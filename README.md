# P2P Chat

Secure peer-to-peer encrypted chat. No servers, no tracking.

**[Open App →](https://nanu-sh.github.io/p2p-chat)**

## Features

- End-to-end encrypted messaging
- 1-on-1 direct chats
- Voice calls
- Media sharing
- Installable PWA
- Dark/Light mode

## Usage

1. Open the app
2. Click "Start New Chat"
3. Share the link with someone
4. Chat

## Run Locally

```bash
git clone https://github.com/nanu-sh/p2p-chat.git
cd p2p-chat
npx http-server -p 8080
```

## Tech

- Vanilla JS
- [Trystero](https://github.com/dmotz/trystero) for P2P
- Web Crypto API for encryption
